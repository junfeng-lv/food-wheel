# 今天吃什么（Food Wheel）

一个简单好用的安卓转盘 App，帮你解决“今天吃什么”的选择困难。

## 功能
- 可自定义转盘选项，随机选中今天吃什么
- 转动时播放单车链子音效，每次完整旋转 7 圈
- 支持使用自己的照片作为背景
- 内置多套壁纸和菜谱页面

## 安装
下载 `dist/今天吃什么_v1.2.apk` 并安装到安卓手机即可使用。

## 从源码构建
项目使用自定义无 Gradle 构建脚本，准备好 Android SDK 后运行：

```powershell
.\build-apk.ps1
```
